🌳 Linktree Pessoal

Este projeto é uma página estilo Linktree, criada para centralizar todos os meus links importantes em um único lugar.

🚀 Sobre o Projeto

Este site foi desenvolvido com o objetivo de:

Reunir meus links em uma única página

Facilitar o acesso às minhas redes sociais

Servir como cartão de visita digital

Praticar desenvolvimento web

🛠️ Tecnologias Utilizadas

HTML5

CSS3

(Opcional) JavaScript

(Opcional) Responsividade com Media Queries

📱 Funcionalidades

✅ Links para redes sociais

✅ Design moderno e minimalista

✅ Layout responsivo

✅ Ícones personalizados

✅ Fácil de editar
